# Australian Visa Rule & Regulation RAG Chatbot

An evidence-based Retrieval-Augmented Generation system for
Australian visa rules, requirements, regulations, policy changes,
legislative changes, and related immigration information.

## Project Goals

- Authoritative sources
- Source citations
- Version-aware retrieval
- Current and historical information
- Transparent evidence
- Modular architecture
- Testability
- Auditability

## RAG Pipeline

Official Sources
→ Ingestion
→ Text Extraction
→ Normalization
→ Metadata
→ Chunking
→ Embeddings
→ Vector Database
→ Retrieval
→ LLM
→ Citations
→ User Interface

## Current Stage

Project initialization.

## Important

This project is an information-retrieval system.

It does not provide legal advice, guarantee visa eligibility,
or make government decisions.
